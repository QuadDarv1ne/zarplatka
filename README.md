# Zarplatka

Статистика зарплат, цены и открытые данные по России и странам мира.

Аналог rgex.ru, построенный на современной архитектуре.

## Технологии

- **Next.js 16** с App Router
- **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui**
- **Recharts** — интерактивные графики
- **next-themes** — тёмная/светлая тема
- **Framer Motion** (доступен)

## Функции

- Международное сравнение зарплат (178 стран)
- Динамика зарплат (Россия vs мир, 2018–2026)
- Зарплаты по размеру компаний (BarChart)
- Распределение доходов по Джини (PieChart)
- Рейтинги регионов и городов России
- 453+ профессий и отрасли
- 18 рейтингов с поиском и фильтрацией
- FAQ-аккордеон
- Тёмная/светлая тема
- Анимированные счётчики при скролле
- Кнопка «Наверх»
- Полная адаптивность (mobile-first)

## Запуск

```bash
bun install
bun run dev
```

Открыть http://localhost:3000

Проект и его интеллектуальную собственность защищают следующие нормативные акты Российской Федерации:

### Авторское право и программный код

- **Гражданский кодекс РФ, часть четвёртая** (гл. 69–77, ст. 1225–1551) — основной закон об интеллектуальной собственности:

  - **ст. 1261–1262** — программы для ЭВМ охраняются как литературные произведения;
  - **ст. 1229** — исключительные права, позволяющие использовать произведение любым способом и запрещать это третьим лицам;
  - **ст. 1301** — ответственность за нарушение исключительных прав.
- **УК РФ, ст. 146** — уголовная ответственность за нарушение авторских и смежных прав.
- **КоАП РФ, ст. 7.12** — административная ответственность за незаконное использование объектов авторского права.

### Базы данных

- **ГК РФ, гл. 71** (ст. 1333–1336) — права изготовителя базы данных; наборы данных проекта охраняются от несанкционированного извлечения (ст. 1334).

- **ГК РФ, гл. 76** (ст. 1477–1515) — правовая охрана товарного знака и его защита от незаконного использования.

### Коммерческая тайна

- **ГК РФ, гл. 75** (ст. 1465–1470) — режим коммерческой тайны для закрытых данных и исходного кода.
- **ФЗ № 98-ФЗ «О коммерческой тайне»** — порядок отнесения информации к коммерческой тайне.
- **УК РФ, ст. 183** — уголовная ответственность за разглашение коммерческой тайны.

- **ФЗ № 149-ФЗ «Об информации, информационных технологиях и о защите информации»** — регулирование оборота информации в интернете.
